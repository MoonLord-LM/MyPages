文件编解码 - PEM 格式

批处理脚本（与网页功能一致）： 文件编解码 - 编码 pem 格式.bat 文件编解码 - 解码 pem 格式.bat 开源仓库：MyBatch
将输入的二进制文件编码为 PEM 文本格式，或将其解码还原为原始文件。
PEM 格式使用 Base64 编码，并包裹 -----BEGIN CERTIFICATE----- / -----END CERTIFICATE----- 标记，每行 64 字符，编码后体积约为原文件的 1.33 倍。
编码：输出文件名将在原文件名后追加 .pem 后缀。
解码：会自动去除 .pem 后缀，恢复原文件名。
全程在浏览器本地完成，不会上传任何数据。
点击选择 或将文件拖拽到此处
