文件加解密 - AES-256-GCM 算法

批处理脚本（与网页功能一致）： 文件加解密 - 加密.bat 文件加解密 - 解密.bat 开源仓库：MyBatch
将输入的密码使用 PBKDF2-HMAC-SHA512（迭代 1000 万次）派生出 256 位密钥，再对文件进行 AES-256-GCM 加解密。
加密文件布局为 pbkdf2_salt (16 字节) + aes_gcm_iv (12 字节) + aes_gcm_tag (16 字节) 头部 + 文件内容密文，因此加密文件比原文件大 44 字节。
加密：输出文件名将在原文件名后追加 .enc 后缀。
解密：会自动去除 .enc 后缀，恢复原文件名。
全程在浏览器本地完成，不会上传任何数据。
